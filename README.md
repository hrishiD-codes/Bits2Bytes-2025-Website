
# Bits2Bytes 2025 Official Website

Welcome to the official repository for the **Bits2Bytes 2025** college fest website. This project serves as the digital platform for all information, updates, and resources related to the annual fest organized by Techno Bengal Institue of Technology, Kolkata.

## Overview

Bits2Bytes is a flagship technical fest, bringing together students, faculty, and industry professionals to celebrate innovation, creativity, and collaboration. The website provides details about events, schedules, teams, contact information, and more.



## Getting Started

To set up the project locally:

1. Clone the repository:
	```powershell
	git clone https://github.com/hrishiD-codes/Bits2Bytes-2025-Website.git
	```
2. Navigate to the project directory:
	```powershell
	cd Bits2Bytes-2025-Website
	```
3. Install dependencies:
	```powershell
	npm install
	```
4. Start the development server:
	```powershell
	npm run dev
	```
5. Open your browser and visit `http://localhost:3000`.
